# Gordinho Locacoes

**Tipo:** Aplicação web
**Stack:** Next.js, Node.js
**Local:** `C:\Users\arino\OneDrive\Documentos\Projetos\Gordinho Locacoes`

## Descrição

Aplicação web para a Gordinho Locações, com banco de dados, API e testes automatizados.

## Estrutura

- `src/` — Código-fonte da aplicação
- `db/` — Banco de dados
- `api/` — Rotas da API
- `tests/` — Testes automatizados
- `public/` — Arquivos estáticos
- `scripts/` — Scripts utilitários

## Comandos

```bash
npm run dev     # Desenvolvimento
npm run build   # Build de produção
npm start       # Iniciar produção
npm test        # Testes
```
